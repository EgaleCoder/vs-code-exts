## 🚀 How to Start in VS Code

### 1. Automatic Activation
Once installed, **EGALE PULSE** is active immediately:
- Look at the **bottom-right corner** of your status bar to see live speed, CPU load, and RAM usage:
  `⚡ EGALE PULSE: 🌐 93.3 Mbps | ⚡ 27% | 🧠 88%`

### 2. Instant Tooltip Breakdown
- Hover your cursor over the status bar item to view ping latency, active CPU core counts, used vs. total GB RAM, and system uptime.

### 3. Open the Telemetry Dashboard
Launch the interactive dashboard at any time using:
* **🖱️ One-Click**: Click the bottom-right status bar item.
* **⌨️ Keyboard Shortcut**: Press `Ctrl + Alt + E` (`Cmd + Alt + E` on macOS).
* **🔍 Command Palette**: Press `Ctrl + Shift + P` (`Cmd + Shift + P`), type `EGALE PULSE: Open Real-Time System Dashboard`, and press Enter.
* **🦅 Activity Bar**: Click the **EGALE PULSE** icon on your VS Code sidebar.

## 🌟 Key Features

* 🌐 **Real-Time Internet Speed**: Live measurement of connection throughput (Mbps), ping latency (ms), and network stability (`ONLINE` / `LATENCY HIGH` / `OFFLINE`).
* ⚡ **Real-Time CPU Usage**: Active CPU percentage, multi-core monitoring, and dynamic load bar.
* 🧠 **Real-Time Memory Usage**: Live RAM consumption in GB (`Used / Total GB`) and percentage with health status badges.
* 🦅 **Official Cyber Branding**: Styled with `ECLogo.png` logo and futuristic typography.
* 📍 **Bottom-Right Corner Status Bar**: Always visible, lightweight, and non-intrusive.
