## 🌟 Why EgaleCoder?

Coding can be stressful. Why code alone when you can have a supersonic raptor companion soaring across your workspace, hunting syntax errors in your files, and screeching developer wisdom when you need a boost?

EgaleCoder blends **fluid aesthetics**, **dynamic interactive physics**, and **real developer utility** into an unforgettable VS Code experience.

---

## ✨ Features

### 1. 🚀 Full Workspace Sky Flight Mode (`Ctrl+Alt+E`)
Open an interactive 60fps flight canvas right inside your editor tabs:
* **Aerodynamic Physics**: Realistic wing flapping, banking turns, lift, drag, and diving physics.
* **Interactive Flight**: The eagle follows your cursor, swoops on clicks, or executes high-speed dives.
* **Themes & Skies**: Choose between *Cyberpunk Sunset*, *Golden Hour*, *Azure Daylight*, and *Deep Midnight*.
* **Custom Skins**: Switch on-the-fly between *Golden Eagle*, *Cyber Raptor*, *Bald Eagle*, *Phoenix Flame*, and *Pixel Eagle*.
* **Particle Engine**: Dynamic golden sparks, cyber grid trails, and cloud formations with coding keywords.

### 2. 👁️ In-Editor Code Patrol (`Ctrl+Alt+P`)
Let EgaleCoder soar directly through the text of your active code file:
* Flies smoothly along line numbers and margins.
* Perches on comments (`//`, `/*`), function declarations, and classes.
* Spots diagnostics and syntax bugs in your code.
* Hover over the eagle on any line to check altitude, airspeed, and inspiring raptor wisdom.

### 3. 🎯 Linter Bug Hunting
Turn real linter errors into prey!
* EgaleCoder inspects VS Code diagnostics across your workspace.
* Scented bugs appear floating in the airspace.
* EgaleCoder dives at high velocity, catches the bug with its talons, triggers celebratory sound FX and explosion bursts!

### 4. 📢 Procedural Audio Synthesizer
* **Zero External Dependencies**: Screeches, wing whooshes, and bug-catch chimes are synthesized directly in your browser using the Web Audio API.
* Easily toggle sound on or off from the HUD or settings.

### 5. 🏰 Activity Bar Nest & Telemetry HUD
* Dedicated sidebar in your VS Code Activity Bar (`EgaleCoder Nest`).
* Live telemetry: Altitude (ft), Airspeed (mph), Bugs Snatched, Lines Patrolled, and Stamina.
* Quick action buttons to launch flight, hunt bugs, screech, or feed snacks.

## 🎮 Keybindings & Commands

| Command | Title | Default Keybinding | Description |
| :--- | :--- | :---: | :--- |
| `egalecoder.summon` | **EgaleCoder: Summon Sky Flight** | `Ctrl+Alt+E` (`Cmd+Alt+E`) | Launch the full interactive flight simulator. |
| `egalecoder.toggleEditorPatrol` | **EgaleCoder: Toggle In-Editor Soaring** | `Ctrl+Alt+P` (`Cmd+Alt+P`) | Start/pause eagle flying through code lines. |
| `egalecoder.huntBugs` | **EgaleCoder: Hunt Workspace Bugs** | — | Eagle targets and dives at syntax errors. |
| `egalecoder.screech` | **EgaleCoder: Screech & Wisdom** | — | Plays synthesized screech & delivers quote. |
| `egalecoder.feed` | **EgaleCoder: Feed Snack** | — | Feeds EgaleCoder and restores 100% stamina. |
| `egalecoder.changeSkin` | **EgaleCoder: Change Eagle Skin** | — | QuickPick menu to choose eagle visual appearance. |
| `egalecoder.changeTheme` | **EgaleCoder: Change Sky Theme** | — | Switch between Cyberpunk, Sunset, Day, Night. |
| `egalecoder.toggleNest` | **EgaleCoder: Open Nest Sidebar** | — | Focus the Activity Bar telemetry panel. |

## ⚙️ Extension Settings

Configure EgaleCoder to your liking in `settings.json`:

```json
{
  // Flight speed across workspace: "relaxed" | "normal" | "turbo" | "hypersonic"
  "egalecoder.flightSpeed": "normal",

  // Visual skin for EgaleCoder: "golden" | "cyber" | "bald" | "phoenix" | "pixel"
  "egalecoder.eagleSkin": "golden",

  // Sky environment theme: "cyberpunk" | "sunset" | "daylight" | "midnight"
  "egalecoder.skyTheme": "cyberpunk",

  // Enable procedural Web Audio sound FX
  "egalecoder.soundEnabled": true,

  // Speed in milliseconds between line jumps in in-editor patrol mode
  "egalecoder.editorPatrolSpeedMs": 350,

  // Show motivational eagle coder quotes
  "egalecoder.motivationalQuotes": true
}
```
