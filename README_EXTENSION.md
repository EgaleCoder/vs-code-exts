> **Keep track of your system performance without ever leaving VS Code.**  
> **EGALE CODERS** displays real-time **Internet Speed**, **CPU Usage**, and **Memory Usage** in the bottom-right corner of your workspace with custom EGALE CODERS branding and dashboard.

---

## 🌟 Features

* 🌐 **Real-Time Internet Speed**: Live measurement of connection throughput (Mbps), ping latency (ms), and network stability.
* ⚡ **Real-Time CPU Usage**: Active CPU percentage, core count, and dynamic load bar.
* 🧠 **Real-Time Memory Usage**: Live RAM consumption in GB and percentage with status indicators.
* 🦅 **Official Branding**: Features the `ECLogo.png` logo and futuristic **EGALE CODERS** font typography.
* 📍 **Bottom-Right Corner Status Bar**: Constantly updated metrics in your status bar with one-click dashboard popup.

## 🎮 Commands & Keybindings

| Command | Title | Keybinding | Description |
| :--- | :--- | :---: | :--- |
| `egalecoder.openDashboard` | **EGALE CODERS: Open Real-Time System Dashboard** | `Ctrl+Alt+E` (`Cmd+Alt+E`) | Opens the visual system telemetry dashboard. |
